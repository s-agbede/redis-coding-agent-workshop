Built-in detectors: card numbers, email, IP addresses, phone, US SSNs. Add your own as a regex, or as a plain-language rule.

The session keeps the raw text until it expires. Don’t capture what you couldn’t keep for a day.

Show Store settings → longTermMemoryExclusions in the Agent Memory panel: the built-in email detector redacts, and a custom api-token regex drops the memory. Exclusions run during extraction, so they protect long-term memory only; /events still shows the raw messages until the session’s one-day retention ends. For a bank, that’s the governance question: what may enter session memory at all.
