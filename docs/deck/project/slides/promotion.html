04 · Promotion

From many conversations to one approved answer

Agent Memory

Many people ask

“Can I use real customer data in test fixtures?” Each agent answers its own way

Extraction

A proposal

A drafted FAQ, with the sessions it came from as evidence

A person

Reviewed, accepted

The answer rewritten to the approved one; a draft FAQ, not yet served

Publish

Every agent

Gets the same answer and version, but only when it fits the task

Memory learns for you. Promotion turns what many asked into what the team approved.

Nothing reaches anyone’s agent until a person publishes it.

Iris console (localhost:18080) → Playbook → Proposals. Open the fixture proposal and show its evidence count: one per session that asked. Edit the answer to the approved wording (synthetic data only, never real customer records, even masked), Accept as draft FAQ, then publish it from Entries. Have the room ask the question in their own words: “Team answer: …”. For a bank this is the governance story: extraction proposes, a person approves.
