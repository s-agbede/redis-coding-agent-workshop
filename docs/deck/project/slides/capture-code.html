role

USER or ASSISTANT, so extraction learns your preferences, not the model’s suggestions

actor_id

Your stable owner ID, or coding-assistant

session_id

Groups one conversation’s events

In agent.py’s handle: your message before the model is called, the answer after it. Tool calls aren’t recorded.

Set CAPTURE = True in agent.py and open handle: show the Section 3 step, and Section 3 again for the answer. The roles matter: swap them and extraction would learn the model’s suggestions as your preferences. Save, exit, relaunch, then restate the preference: earlier messages were never recorded.
