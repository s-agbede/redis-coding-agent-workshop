04 · From personal to organisational

A preference is learned. A procedure is published.

Redis Agent Memory

Personal preference

  • Learned from your conversations
  • Scoped to one owner
  • “I like Google-style docstrings”

Redis Agent Playbook

Team procedure

  • Authored and reviewed
  • Published once, versioned
  • Same version for every agent
  • “How reports are validated”
A team rule should not be extracted from one person’s chat. It is authored, reviewed, published once and versioned, and every agent that uses it should get the same version. That is what Redis Agent Playbook does for agent skills.
