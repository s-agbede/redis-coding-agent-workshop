Custom type

coding_preference

Keep only what the user says about how they want code written; ignore what the assistant did

Store settings, not code: whoever runs the store decides what it learns.

Open Agent Memory → Store settings in the workshop. The managed deployment shows a dated, read-only snapshot; attendees do not need dashboard access. The instructor verifies or edits current settings in Redis Cloud → Iris → Agent Memory → the workshop service → Configuration. The coding_preference prompt is the governance point: the store decides what memory keeps, and changes affect everyone using the shared store.
