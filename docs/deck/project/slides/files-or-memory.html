01 · What it costs

Writing it down works, but…

Someone had to write it

Most preferences come up in passing and never get turned into a rule

It applies to everyone

A teammate who likes NumPy-style docstrings now gets yours

It only grows

Every rule rides along in every request, even FizzBuzz

Nothing expires

Change your mind and you have to remember to edit the file

Doing it well takes three jobs. That’s what Redis Agent Memory is for.

Walk through the four costs, then take the rule back out of AGENTS.md (“Remove the docstring line from AGENTS.md.”), so later we know the preference comes from memory, not the file. Having to remember that step is the “nothing expires” problem in miniature.
