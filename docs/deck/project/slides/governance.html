Who can read a memory?

Owner filters select records. Isolation comes from stores, credentials and namespaces.

Can we correct or delete it?

Redis Agent Memory has update and bulk-delete operations for long-term memories.

What about sensitive data?

Extraction learns from what you capture. Decide what to capture; prompts aren’t redaction.

Who approves a procedure?

Playbook separates creating a version from publishing it. Only the publisher needs write access.

How do changes roll out?

Agents load the current published version; its source and version appear in every request.
