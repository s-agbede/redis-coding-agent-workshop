The agent loop in one picture

You

Type a task

Your app

Builds the request

Model

Answers, or asks for a tool

Python tool

Runs it; the result goes back

The tool result goes into the next request. The loop repeats until the model answers.

The model never touches your files. Your code does.

Quick recap of Part 1, about a minute. The model only ever asks for a tool. Our Python code runs it and sends the result back in the next request. If someone missed Part 1, this one picture is all they need.
